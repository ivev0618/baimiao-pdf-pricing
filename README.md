第一类，一个月识别不了几页的人。系统自带的预览、备忘录和截图工具都能提取文字，量小的时候完全够用，为了偶尔几次去装一个专门的工具，纯属折腾。

退款是最需要提前知道的一条。数码荔枝的购买须知写明，数字商品发货后一般不支持退款，除非当地法律或具体售后政策另有规定。他们同时建议先下载试用、确认能用再买。别把“先试后买”当客套话。

“终身”“永久更新”这类表述的责任划分也写在须知里：这些承诺基于开发者提供的信息，后续的更新、维护和政策变化由开发者负责，商城不承担补偿或退款。买之前把这句话读一遍，心理预期会正常很多。

设备限制是第二常见的坑。授权按设备计算，换机前先解绑旧设备，不然新机器激活不了，还得回头找客服。

跨大版本升级要不要再付费，商品页写了才算数，别按别人的经验推。

最后是识别效果。扫描件拍歪了、表格线密密麻麻、手写潦草，任何 OCR 都会出错。试用的时候拿你自己最难处理的那份文件去跑，别拿印刷体样张测。
